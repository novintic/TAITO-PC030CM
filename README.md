This is a Replica of the TAITO PC0030CM hybrid IC used to manage coin inputs and counters (that red ceramic package thingie). It is used on the Bubble Bobble CPU Board and other TAITO games.

If missing or corrupt, the board will report I/O error.

The coin-counter function has not been tested as we don't have any such counters.
